# 📘 Data Structures & Algorithms in Java

This is my personal DSA learning repo. I'm working through **Striver's A2Z DSA Sheet** in Java, topic by topic, and committing my solutions along with notes on the approach and complexity for each problem.

The goal is to understand the patterns, not just get accepted answers: brute force → better → optimal.
